---
title: Using deploy hooks
description: Trigger a deploy from CI, a CMS or a cron job.
---

A deploy hook is a secret URL that deploys a service, or every service in a project, with its current settings. Git services build the <Term tip="The latest commit on the branch.">head</Term> of their branch. A project's hook skips stopped services.

Create one from the service or project, then call it:

```bash
curl -X POST https://your-pyo/api/hooks/deploy/<token>
```

Anyone with the URL can trigger a deploy, so treat it like a password. You can remove a hook at any time.
