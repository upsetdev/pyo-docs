Pyo Cloud is Pyo run by us at `cloud.pyo.dev`. You sign up, connect your own servers, and deploy. We run and update the dashboard, the API and Pyo's database. Your services, databases, builds and traffic stay on your servers.

It's the same Pyo as self-hosted, with the same dashboard, [CLI](/docs/cli), [API](/docs/api) and [MCP](/docs/mcp).

It costs $5 per server per month, with everything included and unlimited users. See [Billing](/docs/cloud/billing).

## How it works

Each server runs k3s and the Pyo agent, which the connect command installs. The agent dials out to Pyo Cloud over HTTPS, so nothing on your server listens for us. Every command Pyo Cloud sends to it is signed, and the agent refuses anything that isn't. See [Security](/docs/cloud/security).

Visitors reach your services directly on your servers, through [Pyo Gateway](/docs/gateway). Their traffic never goes through Pyo Cloud.
