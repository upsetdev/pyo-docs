```text

Options:
  -s, --service <SERVICE>  The service: a name ("api", "shop/api") or id. Default: pyo.toml's

      --token <TOKEN>      An API key, for CI (default: the one `pyo login` saved) [env: PYO_TOKEN]

Usage: pyo import [OPTIONS] --from <FROM> --source-token <SOURCE_TOKEN> <PLATFORM>

Arguments:
  <PLATFORM>  The platform: coolify or dokploy [possible values: coolify, dokploy]

Options:
      --from <FROM>                  Its address, e.g. https://coolify.example.com
      --url <URL>                    Your Pyo, e.g. https://pyo.example.com (default: the one you signed in to) [env: PYO_URL]
      --source-token <SOURCE_TOKEN>  Its API token (Coolify's with read and read:sensitive). Used for this import only [env: PYO_IMPORT_TOKEN]
      --token <TOKEN>                An API key, for CI (default: the one `pyo login` saved) [env: PYO_TOKEN]
      --team <TEAM>                  The team to import into (slug or id). Defaults to your first team
      --cluster <CLUSTER>            The cluster to run it on (name or id). Defaults to the team's default cluster
      --deploy                       Deploy the services once they're made
  -y, --yes                          Import without asking
  -h, --help                         Print help
  -V, --version                      Print version
```

## `pyo backup`

Backups of volumes and databases

```text
Backups of volumes and databases

Usage: pyo backup [OPTIONS] <COMMAND>

Commands:
  now   Back up a volume or database now
  help  Print this message or the help of the given subcommand(s)

Options:
      --url <URL>          Your Pyo, e.g. https://pyo.example.com (default: the one you signed in to) [env: PYO_URL]
  -s, --service <SERVICE>  The service: a name ("api", "shop/api") or id. Default: pyo.toml's
      --token <TOKEN>      An API key, for CI (default: the one `pyo login` saved) [env: PYO_TOKEN]
  -h, --help               Print help
  -V, --version            Print version
```

### `pyo backup now`

Back up a volume or database now.

```text
Back up a volume or database now.

Without --volume or --db: the service's volume, when it has one.

Usage: pyo backup now [OPTIONS]

Options:
      --url <URL>
          Your Pyo, e.g. https://pyo.example.com (default: the one you signed in to)
          
          [env: PYO_URL]

      --volume <VOLUME>
          The volume: an id, "name" or "project/name"

      --db <DB>
          The database: its name or id

  -s, --service <SERVICE>
          The service: a name ("api", "shop/api") or id. Default: pyo.toml's

      --token <TOKEN>
          An API key, for CI (default: the one `pyo login` saved)
          
          [env: PYO_TOKEN]

      --wait
          Wait until it's done

  -h, --help
          Print help (see a summary with '-h')

  -V, --version
          Print version
```
